# Fake News Detection — roadmap

Owner and primary developer: **Priti Kumari**. Milestones are acceptance gates, not promised dates.

## Current useful MVP

Implemented: calibrated English article predictions, feature explanations/abstention, public URL extraction, local image OCR, short audio/video speech extraction, frame timeline, evidence notebook and exact citations, browser history/deletion, JSON/print PDF, metrics and provider-dependent international search. Experimental: CLIP comparison, NLI wording assistance, Hindi extraction and C2PA inspection with signer trust unchecked. Unavailable: automatic validated factual verdicts, Hindi veracity classification, full-media/deepfake classifiers, authenticated durable history and long-video server jobs.

## Short term

1. Verify Phase 0 planning and renamed identity against the existing deployed foundation.
2. Complete Phase 1 reproducible setup and CI audit.
3. Build Phase 2 navy/cyan/violet design system, landing/report/settings navigation and real analysis analytics with empty states.
4. Provision and test Phase 3 authenticated storage with per-record ownership and deletion.
5. Establish licensed evaluation corpora and claims/citation review protocol before expanding model or factual claims.

## Following milestones

English/Hindi NLP evaluation; grounded provider-backed evidence verification; richer image metadata/context review; durable isolated FFmpeg jobs for longer videos; paired fusion ablations; authenticated reports/history; consolidated MLOps and public deployment verification. Follow [PHASES.md](PHASES.md) sequentially rather than implementing all eleven phases together.

## Research backlog

XLM-R/mBERT, NER/atomic claims, publisher/temporal generalization, externally evaluated multimodal/forensic models, image reuse providers, attention fusion, multilingual UI/translation and independently reviewed citation correctness. Each needs a license/access review, documented task, disjoint data, recorded execution and a missing-artifact fallback. No universal real-world accuracy target or truth probability is promised.
