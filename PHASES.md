For every phase, create a report with objective; files created/modified; dependencies installed; algorithms; exact commands; actual results; unresolved issues; Git checkpoint; and prerequisites for the next phase. Do not declare completion based only on generated code. If a check cannot execute, record why and keep its dependent gate open. Optional advanced features may remain unavailable but must not be advertised as implemented. No phase requires inventing credentials, licenses or dataset rights.
