## Application decisions

Use the first reference's input/preview/loading separation as a design principle. Use the second's distinct classifier/evidence contracts and checkpoint-readiness checks as architectural guidance. Retain this repository's existing original components, calibrated models, OCR/speech workers, DNS-pinned extraction and traceable citations. External evaluation results belong to their original experiments and must not appear as this project's measurements.

The current repository already supplies a useful MVP. Avoid a Vite migration or duplicate backend while adding capabilities: Next.js is the existing production React host and the prompt permits architecture refinement. Keep browser-local media processing for short clips; future FFmpeg jobs need separate persistent infrastructure. Introduce auth/history and a configured, evaluated evidence service in separate testable phases.
